# 🔨 Инструкция по сборке проекта

## Установка зависимостей

```bash
npm install
```

Это установит все зависимости, включая dev-зависимости для минификации:
- `cssnano` - минификация CSS
- `postcss` - обработка CSS
- `terser` - минификация JavaScript

---

## Минификация файлов

### Автоматическая минификация

```bash
npm run minify
```

Это создаст минифицированные версии:
- `public/css/style.min.css` (из `style.css`)
- `public/js/main.min.js` (из `main.js`)

### Production build

```bash
npm run build
```

Выполняет полную сборку проекта (минификацию всех файлов).

---

## Использование минифицированных версий

### ⚠️ ВАЖНО: Автоматическое обновление HTML

**Для локальной разработки:** Используйте оригинальные файлы (`style.css`, `main.js`)

**Для production:** Используйте скрипт автоматического деплоя `npm run deploy`, который:
1. Минифицирует файлы
2. **Автоматически обновляет HTML** для использования `.min` версий

**Не обновляйте HTML вручную!** Скрипт `deploy.js` сделает это автоматически на сервере.

См. `DEPLOY_GUIDE.md` для подробной инструкции по настройке автоматического деплоя.

|------|-----|-------|----------|
| `style.css` | ~55 KB | ~35-40 KB | ~30-35% |

| **Итого** | **~139 KB** | **~85-95 KB** | **~35%** |

## Важные замечания

1. **Минифицированные файлы не перезаписывают оригиналы** - создаются новые файлы с расширением `.min.*`

2. **Для production используйте минифицированные версии** - они значительно меньше по размеру

3. **Для разработки используйте оригинальные файлы** - они читаемы и удобны для отладки

4. **После изменений в CSS/JS** - запустите `npm run minify` снова для обновления минифицированных версий

## Автоматизация (опционально)

Можно настроить автоматическую минификацию при деплое:

1. Добавить в CI/CD pipeline команду `npm run build`
2. Или использовать pre-commit hook для автоматической минификации перед коммитом

---

## Проверка минификации

После минификации проверьте:

1. **Размер файлов** - должны быть меньше оригиналов
2. **Функциональность** - сайт должен работать так же, как с оригинальными файлами
3. **Производительность** - время загрузки должно уменьшиться

---

## Откат к оригинальным версиям

Если нужно вернуться к оригинальным файлам, просто обновите ссылки в HTML обратно на файлы без `.min`.

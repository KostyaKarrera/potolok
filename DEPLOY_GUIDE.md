# 🚀 Руководство по автоматическому деплою

## Текущий workflow

```
Cursor (локальная разработка) 
  → GitHub (main ветка) 
  → git pull на сервере
  → автоматический деплой
```

---

## Настройка автоматического деплоя

### Рекомендуемый способ: Git hook (автоматически после pull)

Git hook будет автоматически запускаться после каждого `git pull` и выполнять:
1. Установку зависимостей
2. Минификацию CSS и JS
3. Обновление HTML для использования минифицированных версий
4. Перезапуск сервера

---

## Детальная инструкция по настройке

### Шаг 1: Подключитесь к серверу

```bash
ssh ваш_пользователь@ваш_сервер
```

### Шаг 2: Перейдите в директорию проекта

```bash
cd /путь/к/вашему/проекту
# Например: cd /var/www/potolok
```

### Шаг 3: Проверьте, что вы в корне проекта

Убедитесь, что вы видите файлы:
- `package.json`
- `server.js`
- `public/`
- `.git/`

```bash
ls -la
```

### Шаг 4: Создайте Git hook

Создайте файл `.git/hooks/post-merge`:

```bash
nano .git/hooks/post-merge
```

Или используйте другой редактор (vim, vi, etc.)

### Шаг 5: Вставьте следующий код в файл

```bash
#!/bin/bash

echo "=========================================="
echo "🚀 Автоматический деплой после git pull"
echo "=========================================="
echo ""

# Шаг 1: Установка зависимостей
echo "📦 Шаг 1: Установка зависимостей..."
npm install --production=false
if [ $? -ne 0 ]; then
    echo "❌ Ошибка при установке зависимостей!"
    exit 1
fi
echo "✅ Зависимости установлены"
echo ""

# Шаг 2: Запуск автоматического деплоя
echo "🔨 Шаг 2: Минификация и обновление файлов..."
NODE_ENV=production npm run deploy
if [ $? -ne 0 ]; then
    echo "❌ Ошибка при деплое!"
    exit 1
fi
echo "✅ Деплой выполнен успешно"
echo ""

# Шаг 3: Перезапуск сервера
echo "🔄 Шаг 3: Перезапуск сервера..."
sudo systemctl restart potolok.service
if [ $? -ne 0 ]; then
    echo "⚠️  Предупреждение: не удалось перезапустить сервер автоматически"
    echo "   Перезапустите вручную: sudo systemctl restart potolok.service"
else
    echo "✅ Сервер перезапущен"
fi
echo ""

echo "=========================================="
echo "✅ Деплой завершен успешно!"
echo "=========================================="
```

### Шаг 6: Сохраните файл

- В `nano`: нажмите `Ctrl+O` (сохранить), затем `Enter`, затем `Ctrl+X` (выйти)
- В `vim`: нажмите `Esc`, затем введите `:wq` и нажмите `Enter`

### Шаг 7: Сделайте файл исполняемым

```bash
chmod +x .git/hooks/post-merge
```

### Шаг 8: Проверьте права доступа

```bash
ls -l .git/hooks/post-merge
```

Должно быть что-то вроде:
```
-rwxr-xr-x 1 user user 1234 Jan 15 12:00 .git/hooks/post-merge
```

Обратите внимание на `x` (исполняемый) в правах доступа.

### Шаг 9: Проверьте настройку sudo (опционально)

Если при перезапуске сервера требуется пароль, настройте sudo без пароля для команды `systemctl restart potolok.service`:

```bash
sudo visudo
```

Добавьте в конец файла (замените `ваш_пользователь` на ваше имя пользователя):

```
ваш_пользователь ALL=(ALL) NOPASSWD: /bin/systemctl restart potolok.service
```

Сохраните и выйдите.

**Важно:** Это позволит перезапускать сервис без ввода пароля. Если вы не хотите настраивать это, hook все равно будет работать, но потребует ввода пароля при перезапуске.


```bash

```

## Что происходит при деплое

### 1. Установка зависимостей (`npm install`)

- Устанавливает все зависимости из `package.json`
- Включая dev-зависимости для минификации (cssnano, postcss, terser)

### 2. Минификация (`npm run deploy`)

Скрипт `scripts/deploy.js` выполняет:

**2.1. Минификация CSS:**
- Читает `public/css/style.css`
- Создает минифицированную версию `public/css/style.min.css`
- Экономия: ~30-35% размера

**2.2. Минификация JS:**
- Читает `public/js/main.js`
- Создает минифицированную версию `public/js/main.min.js`
- Экономия: ~35-40% размера

**2.3. Обновление HTML файлов:**
Автоматически обновляет ссылки в следующих файлах:
- `public/index.html`
- `public/ready-solutions.html`
- `public/cheboksary/index.html`
- `public/novocheboksarsk/index.html`
- `public/yoshkar-ola/index.html`

Заменяет:
- `/css/style.css` → `/css/style.min.css`
- `/js/main.js` → `/js/main.min.js`

### 3. Перезапуск сервера

- Выполняет `sudo systemctl restart potolok.service`
- Применяет все изменения

## Структура файлов

```
public/
├── css/
│   ├── style.css          ← Оригинал (для разработки)
│   └── style.min.css      ← Минифицированный (для production, создается автоматически)
├── js/
│   ├── main.js            ← Оригинал (для разработки)
│   └── main.min.js        ← Минифицированный (для production, создается автоматически)
└── index.html             ← Обновляется автоматически для использования .min версий
```

**Важно:** Минифицированные файлы (`.min.*`) создаются автоматически и не должны коммититься в Git. Они генерируются на сервере при деплое.

## Проверка работы после деплоя

### 1. Проверка размера файлов

```bash
ls -lh public/css/style*.css
ls -lh public/js/main*.js
```

Минифицированные файлы должны быть меньше оригиналов.

### 2. Проверка HTML файлов

```bash
grep "style.min.css" public/index.html
grep "main.min.js" public/index.html
```

Должны содержать ссылки на `.min` версии.

### 3. Проверка работы сайта

1. Откройте сайт в браузере
2. Откройте DevTools → Network (F12)
3. Проверьте загружаемые файлы
4. Должны загружаться `.min` версии файлов

### 4. Проверка статуса сервиса

```bash
sudo systemctl status potolok.service
```

Должен быть активен и работать.

## Troubleshooting

### Проблема: Hook не запускается после git pull

**Причины:**
- Файл не исполняемый
- Неправильный путь к файлу
- Проблемы с правами доступа

**Решение:**
```bash
# Проверьте права
ls -l .git/hooks/post-merge

# Сделайте исполняемым
chmod +x .git/hooks/post-merge

# Проверьте содержимое
cat .git/hooks/post-merge
```

### Проблема: Ошибка "npm: command not found"

**Решение:**
```bash
# Проверьте, установлен ли Node.js
node --version
npm --version

# Если не установлен, установите Node.js
# Или используйте полный путь к npm
/usr/bin/npm install
```

### Проблема: Ошибка минификации

**Решение:**
```bash
# Проверьте, установлены ли зависимости
npm install

# Запустите минификацию вручную
npm run minify

# Проверьте логи
npm run deploy
```

### Проблема: Сервер не перезапускается

**Решение:**
```bash
# Проверьте права sudo
sudo systemctl restart potolok.service

# Если требует пароль, настройте sudo без пароля (см. Шаг 9)
# Или перезапустите вручную после деплоя
```

### Проблема: HTML файлы не обновляются

**Решение:**
```bash
# Проверьте права доступа к файлам
ls -l public/index.html

# Запустите деплой вручную
NODE_ENV=production npm run deploy

# Проверьте вывод на ошибки
```

### Проблема: Изменения не применяются

**Решение:**
1. Проверьте, что сервер перезапустился: `sudo systemctl status potolok.service`
2. Очистите кэш браузера (Ctrl+Shift+R)
3. Проверьте, что загружаются `.min` версии в Network tab

## Отключение автоматического деплоя

Если нужно временно отключить автоматический деплой:

```bash
# Переименуйте hook
mv .git/hooks/post-merge .git/hooks/post-merge.disabled

# Для включения обратно
mv .git/hooks/post-merge.disabled .git/hooks/post-merge
```

# 🔧 Решение конфликта при git pull

## Проблема

При выполнении `git pull` возникает ошибка:
```
error: The following untracked working tree files would be overwritten by merge:
    public/jobs/mobile/IMG_0423.webp
    ...
Please move or remove them before you merge.
```

## Причина

Мобильные изображения были созданы локально на сервере, но они не должны быть в Git репозитории, так как генерируются автоматически.

## Решение

### Вариант 1: Удалить локальные файлы (рекомендуется)

Мобильные изображения будут созданы автоматически при следующем деплое.

```bash
# Удалите папку с мобильными изображениями
rm -rf public/jobs/mobile/

# Теперь выполните git pull
git pull origin main
```

После `git pull` hook автоматически создаст мобильные изображения заново (если настроен скрипт генерации).

**Но так как у нас нет скрипта генерации в deploy.js, нужно:**

1. После `git pull` выполните вручную (один раз):
```bash
# Создайте мобильные версии изображений вручную
# Используйте ImageMagick или другой инструмент
# Или скопируйте их обратно после pull
```

2. Или просто оставьте их как есть (см. Вариант 2)

### Вариант 2: Сохранить локальные файлы

Если хотите сохранить уже созданные мобильные изображения:

```bash
# 1. Временно переместите файлы
mkdir -p /tmp/mobile-backup
mv public/jobs/mobile/* /tmp/mobile-backup/

# 2. Выполните git pull
git pull origin main

# 3. Верните файлы обратно
mv /tmp/mobile-backup/* public/jobs/mobile/
rmdir /tmp/mobile-backup
```

### Вариант 3: Добавить в .gitignore и продолжить

Файлы уже добавлены в `.gitignore`, но нужно очистить конфликт:

```bash
# 1. Удалите локальные файлы
rm -rf public/jobs/mobile/

# 2. Выполните git pull
git pull origin main

# 3. Мобильные изображения нужно будет создать заново
# (они не должны быть в Git, так как генерируются автоматически)
```

## После решения конфликта

После успешного `git pull`:

1. **Проверьте, что hook работает:**
```bash
.git/hooks/post-merge
```

2. **Если мобильные изображения отсутствуют**, создайте их вручную или добавьте скрипт генерации в deploy.js

3. **Проверьте работу сайта:**
```bash
# Проверьте, что мобильные изображения существуют
ls -la public/jobs/mobile/
```

## Предотвращение проблемы в будущем

Файлы `public/jobs/mobile/` и минифицированные файлы (`.min.css`, `.min.js`) теперь добавлены в `.gitignore`, поэтому они не будут конфликтовать с Git.

**Важно:** Эти файлы генерируются автоматически и не должны быть в репозитории.

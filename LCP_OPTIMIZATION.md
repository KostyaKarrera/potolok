# Оптимизация LCP и FCP

## Проблемы
- **LCP (Largest Contentful Paint)**: 6.8 сек (цель < 2.5s) ❌
- **FCP (First Contentful Paint)**: 4.1 сек (цель < 1.8s) ❌
- **Speed Index**: 4.9 сек (цель < 3.4s) ❌

## Выполненные оптимизации

### 1. ✅ Замена CSS background на `<img>` элемент
**Проблема**: CSS background-image не может быть LCP элементом, браузер не может оптимизировать его загрузку.

**Решение**: 
- Заменен `background-image` на `<img>` элемент с `picture` и `source`
- Это позволяет браузеру определить LCP элемент и оптимизировать его загрузку
- Использован `fetchpriority="high"` для приоритетной загрузки
- Добавлен `loading="eager"` для немедленной загрузки

### 2. ✅ Inline критический CSS
**Проблема**: CSS файл блокирует рендеринг, увеличивая FCP.

**Решение**:
- Добавлен inline критический CSS в `<head>`
- Критический CSS включает стили для:
  - Базовые стили body
  - Topbar (шапка)
  - Hero секция
  - Логотип
- Это позволяет отобразить контент выше сгиба без ожидания загрузки CSS файла

### 3. ✅ Оптимизация preload
- Добавлен `fetchpriority="high"` для hero изображения
- Добавлены `imagesrcset` и `imagesizes` для правильного preload

## Дополнительные рекомендации

### Критично для достижения LCP < 2.5s:

1. **Создать мобильную версию hero изображения**
   ```bash
   # Создать папку для мобильных версий
   mkdir -p public/header/mobile
   
   # Оптимизировать изображение для мобильных (примерно 800px ширина)
   # Использовать инструмент типа ImageMagick или Sharp
   convert header-optimized.webp -resize 800x -quality 85 header/mobile/header-mobile.webp
   ```
   
   Затем обновить HTML:
   ```html
   <source media="(max-width: 768px)" srcset="/header/mobile/header-mobile.webp" type="image/webp">
   ```

2. **Оптимизировать размер hero изображения**
   - Текущий размер должен быть < 200KB для мобильных
   - Использовать WebP с качеством 80-85%
   - Рассмотреть AVIF формат (лучшее сжатие)

3. **Использовать CDN для статических ресурсов**
   - Ускорит загрузку изображений
   - Географически ближе к пользователям

4. **Добавить blur-up placeholder**
   - Показывать размытую версию изображения сразу
   - Улучшит воспринимаемую производительность

### Для улучшения FCP:

5. **Минифицировать inline CSS**
   - Уменьшить размер inline критического CSS
   - Удалить неиспользуемые стили

6. **Оптимизировать загрузку шрифтов**
   - Использовать `font-display: swap` (уже есть)
   - Рассмотреть использование системных шрифтов для FCP
   - Preload только критических начертаний

7. **Оптимизировать размер HTML**
   - Минифицировать HTML
   - Удалить неиспользуемые мета-теги

## Ожидаемые результаты

После всех оптимизаций:
- **LCP**: 6.8s → **2.0-2.5s** ✅
- **FCP**: 4.1s → **1.5-1.8s** ✅
- **Speed Index**: 4.9s → **2.5-3.0s** ✅

## Примечания

- Inline CSS увеличивает размер HTML, но значительно улучшает FCP
- `<img>` вместо background улучшает LCP, но требует правильной структуры
- Все изменения протестированы и не нарушают функциональность

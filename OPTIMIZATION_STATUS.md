## 🎯 Дополнительные оптимизации (Фаза 3)

### Приоритет: Высокий

#### 1. Критический CSS (inline)
**Проблема:** CSS файл блокирует рендеринг, увеличивая FCP.

**Решение:** 
- Выделить критический CSS (стили для above-the-fold контента)
- Встроить его в `<head>` как inline стили
- Остальной CSS загружать асинхронно

**Ожидаемый эффект:** FCP улучшится на 0.5-1 секунду

#### 2. Оптимизация размера hero изображения
**Проблема:** Hero изображение может быть слишком большим.

**Решение:**
- Проверить размер `header-optimized.webp`
- Оптимизировать до < 200KB для мобильных
- Создать отдельную мобильную версию (800px ширина)

**Ожидаемый эффект:** LCP улучшится на 1-2 секунды

#### 3. DNS Prefetch для внешних ресурсов
**Проблема:** Задержка при подключении к внешним доменам.

**Решение:**
- Добавить `dns-prefetch` для Google Fonts
- Добавить `dns-prefetch` для других внешних ресурсов (если есть)

**Ожидаемый эффект:** Улучшение на 50-100ms

---

### Приоритет: Средний

#### 4. Оптимизация Font Awesome
**Проблема:** Font Awesome может быть большим файлом.

**Решение:**
- Проверить размер `font-awesome.css`
- Использовать только нужные иконки (tree-shaking)
- Или использовать SVG иконки вместо шрифта

**Ожидаемый эффект:** Экономия 50-100KB

#### 5. Оптимизация загрузки скриптов
**Проблема:** Все скрипты загружаются с defer, но можно оптимизировать.

**Решение:**
- Inputmask можно загружать только на страницах с формами
- Разделить main.js на критический и некритический код

**Ожидаемый эффект:** Улучшение FCP на 200-300ms

#### 6. Оптимизация API запросов
**Проблема:** API запросы могут быть неоптимизированы.

**Решение:**
- Добавить кэширование для `/api/prices` и `/api/products`
- Использовать ETag для валидации кэша
- Батчинг запросов, если возможно

**Ожидаемый эффект:** Улучшение времени ответа API

---

### Приоритет: Низкий

#### 7. Service Worker для офлайн-режима
**Решение:** 
- Кэширование статических ресурсов
- Офлайн-режим для повторных визитов

**Ожидаемый эффект:** Мгновенная загрузка при повторных визитах

#### 8. Оптимизация структуры HTML
**Решение:**
- Удаление лишних пробелов и переносов строк
- Минификация HTML (опционально)

**Ожидаемый эффект:** Небольшое улучшение размера

#### 9. HTTP/2 Server Push
**Решение:**
- Push критических ресурсов (CSS, JS, изображения)

**Ожидаемый эффект:** Улучшение на 100-200ms (требует поддержки сервера)
